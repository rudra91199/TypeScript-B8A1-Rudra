# Assignment: Problem Solving with TypeScript & OOP

## Overview
This folder contains the solutions of 8 problems from assignment 1 of batch 8. It evaluates the skill of solving problem using typescript concepts that are taught in modules and conceptual sessions.

There are two sections in this project.:
1. **Coding Challenges (`solutions.ts`)**: 8 problem-solving tasks covering everything from basic types to Object-Oriented Programming and Asynchronous TypeScript.
2. **Technical Blogs**: Two short markdown articles explaining about type vs interface and type narrowing.

## Coding Problems Summary
All  solutions are implemented in a single `solutions.ts` file without external testing noise. The problems demonstrate practical use cases for:

* **Problem 1 & 2:** Optional/default parameters, union types, and basic type narrowing.
* **Problem 3:** Used readonly tuples for strict coordinate data structures.
* **Problem 4 & 6:** Used Generics with rest parameters and keyof constraints.
* **Problem 5:** Create custom Object structures with interface and array filters.
* **Problem 7:** Used Object Oriented Programming with class inheritance, constructor initialisation and data encapsulation with private and protected.
* **Problem 8:** Handling asynchronous operations utilizing `Promise`, `setTimeout`, and strict Error rejection types.
